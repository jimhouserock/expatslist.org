# expatslist.org Claude Skill

A Claude Code / Claude AI skill for [ExpatsList](https://expatslist.org), a directory and community platform for expats, newcomers, and remote workers living abroad.

See `SKILL.md` for what the platform covers: finding businesses by city or category, listing and claiming a business, verification, community questions, recommendations, classifieds, and safety.

## Using this skill

Copy `SKILL.md` into a project's `.claude/skills/expatslist/` (or `.agents/skills/expatslist/`) directory so Claude can answer questions about how to use the platform.
